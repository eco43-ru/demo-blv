# Карта экологических рисков Кировской области

Интерактивная ГИС-карта и таблицы исходных данных.

## Карта

Строка атрибуции картографических сервисов скрыта. При открытии страницы карта показывает всю Кировскую область.

## Публикация

Загрузите `index.html`, `README.md` и `.nojekyll` в корень репозитория. В **Settings → Pages** выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
