# Карта экологических рисков Кировской области

Интерактивная ГИС-карта и таблицы исходных данных.

## Данные контрагента (DaData)

В карточке предприятия блок «Данные контрагента · DaData» подгружает по ИНН: наименование, ОГРН, дату регистрации, статус, руководителя, адрес, ОКВЭД, ОПФ, ИНН/КПП.

Если организация или ИП ликвидировано, блок подсвечивается красным и показывает метку «ЛИКВИДИРОВАНО».

### Настройка

1. Зарегистрируйтесь на dadata.ru и получите API-ключ и секретный ключ.
2. Создайте бесплатный Cloudflare Worker и вставьте код из файла `worker.js`.
3. В настройках Worker добавьте переменные `DADATA_API_KEY` и `DADATA_SECRET_KEY`.
4. В `index.html` замените `DADATA_PROXY` на адрес вашего Worker, например `https://имя.workers.dev/dadata`.
5. Загрузите обновлённый `index.html` на GitHub Pages.

## Публикация

Загрузите `index.html`, `README.md`, `worker.js` и `.nojekyll` в корень репозитория. В **Settings → Pages** выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
