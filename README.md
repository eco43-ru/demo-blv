# Карта экологических рисков Кировской области

Интерактивная ГИС-карта: объекты, тепловая карта риска, свалки, границы Кировской области и муниципальных районов.

## Публикация на GitHub Pages

1. Загрузите `index.html`, `README.md` и `.nojekyll` в **корень** репозитория.
2. Откройте **Settings → Pages**.
3. Выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Нажмите **Save**.
5. Сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Подложки

По умолчанию используется **Esri Streets**. Если OpenStreetMap недоступен, выберите **Esri Streets** или **CARTO Voyager**.

## Данные

В `index.html` встроены сведения о 1 074 объектах и 116 свалках. Файл содержит ИНН, адреса и координаты; не публикуйте его, если данные предназначены для ограниченного доступа.
