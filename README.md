# Карта экологических рисков Кировской области

Интерактивная ГИС-карта и таблицы исходных данных.

## Актуализация сведений

В разделе «Сведения» у организаций и свалок доступна кнопка «✏️ Актуализировать».

- Для предприятий: широта, долгота, сведения о ОНВОС, дата последней актуализации.
- Для свалок: широта, долгота, площадь, состав отходов, дата последней актуализации.

Изменения сохраняются локально в браузере и сразу отображаются в таблицах и на карте.

## Публикация

Загрузите `index.html`, `README.md` и `.nojekyll` в корень репозитория. В **Settings → Pages** выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
