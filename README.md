# Карта экологических рисков Кировской области

Интерактивная ГИС-карта и таблицы исходных данных по предприятиям, свалкам и муниципальным районам Кировской области.

## Разделы сайта

- **Карта** — интерактивная карта с предприятиями, свалками, тепловой картой риска и границами.
- **Сведения** — таблицы по организациям, свалкам и муниципальным районам с поиском, фильтрами и экспортом.
- **Мероприятия** — учёт проведённых мероприятий с добавлением, редактированием и удалением записей.

## Карта

- Тёплая карта риска по предприятиям.
- Точки предприятий с цветовой индикацией уровня риска.
- Точки несанкционированных свалок.
- Границы Кировской области и муниципальных районов (загружаются из OpenStreetMap).
- Выбор подложки: Esri Streets, CARTO Voyager, OpenStreetMap, спутниковые снимки Esri, OpenTopoMap.
- Включение и отключение слоёв: границы области, границы районов, тепловая карта, объекты, свалки.
- Кластеризация точек предприятий.
- Инструмент «Рулетка» для измерения расстояний по карте.
- Всплывающие карточки при клике на точку в свёрнутом режиме панели.

## Поиск и фильтры

- Поиск по названию предприятия, району, адресу и ИНН.
- Фильтр по району.
- Фильтр по уровню риска: критический, высокий, средний, низкий, нет риска.
- Фильтр по минимальному индексу риска.
- Результаты поиска отображаются в боковой панели информации.
- Клик по результату открывает карточку предприятия и показывает его на карте.

## Боковая панель информации

- Ширина панели увеличена до 420 px.
- Панель можно расширять или сужать, перетаскивая её левый край.
- Минимальная ширина — 300 px, максимальная — 75% ширины окна.
- Остальные элементы интерфейса (левая панель, карта) размер не меняют.
- Содержимое панели автоматически подстраивается под новую ширину.
- Кнопка **«← Назад к результатам поиска»** возвращает к последнему списку результатов без повторного ввода запроса.
- В карточке предприятия отображаются сведения, мероприятия и мини-карта.
- В карточке района есть переключение между предприятиями и несанкционированными свалками.

## Таблицы «Сведения»

- Три таблицы: организации, свалки, муниципальные районы.
- Поиск по всем полям таблицы.
- Расширенный фильтр по району, уровню риска, статусу ОНВОС, типу свалки, площади, категории района и другим полям.
- Сортировка по любому столбцу.
- Пагинация по 50 записей.
- Раскрывающиеся строки с подробной карточкой и мини-картой.
- Выбор подложки мини-карты: схема, спутник, топографическая.
- Экспорт таблицы в CSV.

## Мероприятия

### Добавление мероприятия

- Поиск организации по названию или ИНН с подсказками (до 50 совпадений).
- Автоматическое заполнение района, ИНН и адреса после выбора предприятия.
- Обязательные поля: организация, ФИО инспектора, мероприятие, дата проведения.
- Необязательное поле «Иные лица, принимающие участие».
- Дополнительные поля в зависимости от типа мероприятия:
  - Проверка предписания: номер, срок исполнения, статус.
  - Инспекционный визит: цель, выявленные нарушения.
  - Предостережение: номер, содержание.
  - Административное правонарушение: номер дела, статья КоАП, размер штрафа.
- Поле «Принятые меры».

### Редактирование и удаление

- Кнопка **✏️ Редактировать** открывает форму с заполненными данными мероприятия.
- Кнопка **🗑️ Удалить** удаляет мероприятие после подтверждения.
- Для обоих действий требуется код администратора.
- Код администратора задаётся в константе `ADMIN_CODE` в начале скрипта.
- При неверном коде действие не выполняется.

### Уведомление о разработке

При открытии раздела «Мероприятия» появляется всплывающее окно:

- Раздел находится в режиме разработки.
- Все сведения о мероприятиях вносятся только в локальные хранилища браузера.
- Работа по синхронизации всех материалов между пользователями продолжается.

Окно закрывается кнопкой «Понятно» или нажатием на затемнённый фон.

## Локальное сохранение

- Все мероприятия сохраняются в localStorage браузера.
- Дополнительно создаётся cookie со сроком хранения до одного года.
- При обновлении страницы или повторном открытии сайта внесённые сведения не сбрасываются.
- Данные можно выгрузить в CSV через кнопку «Скачать CSV».

## Публикация

1. Загрузите в корень репозитория файлы `index.html`, `README.md` и `.nojekyll`.
2. Откройте **Settings → Pages**.
3. Выберите `Deploy from a branch`, ветку `main` и папку `/ (root)`.
4. Сохраните настройки и дождитесь публикации.

## Важно

Локальное сохранение работает только в том браузере, где были добавлены мероприятия. Для общей базы между разными пользователями нужен внешний сервис (например, Firebase Realtime Database).
